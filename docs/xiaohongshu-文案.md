# 小红书文案：Aurora

---

**标题**：我开源了一款 DeepSeek 桌面神器：苹果的颜，Windows 的魂，还能自己动手干活 🤖✨

**正文**：

家人们，我肝了半个月的 DeepSeek 桌面客户端终于开源了！🎉 免费、本地存储、不用注册，Windows 双击就能用！

🌟 **颜值这块**：毛玻璃三栏工作台，深浅色自动切换，Win11 原生窗口按钮，丝滑得不像程序员写的

💬 **聊天体验**：
✅ 流式输出 + 思维链折叠面板（reasoner 思考过程一目了然）
✅ Markdown / 代码高亮 / 数学公式全渲染，代码一键复制
✅ 消息能编辑、能重新生成、能导出 Markdown/JSON
✅ Token 统计 + 费用估算，花多少钱心里有数
✅ 多模型随便切：DeepSeek 官方、Ollama、中转站全支持

🤖 **最炸的是它能真干活**（不是只会说）：
• 让 AI 直接**读写你的文件**（沙箱隔离，不乱碰）
• **跑 Python 代码**、执行系统命令（有确认弹窗+白名单）
• **联网搜索**实时信息，结果带引用卡片
• **本地知识库 RAG**：把你的笔记文件夹变成 AI 的外挂大脑，文档永不外传 🔒
• 支持 **MCP 协议**，接各种工具生态

🔒 **隐私狂魔放心**：数据全在你电脑里，API Key 用 Windows DPAPI 加密，每天自动备份

🖥️ **快捷键党狂喜**：Ctrl+K 命令面板、Ctrl+N 新对话、Ctrl+Shift+A 全局唤起，手不离键盘

💡 适合谁：写代码的、做研究的、囤笔记的、折腾 AI Agent 的

🔗 **开源地址**：GitHub 搜索 **Aurora**（完整安装包在 Releases，MIT 协议随便改）
📖 使用教程、快捷键表、MCP 玩法都在仓库文档里

⚠️ 完全免费，就是想让更多人用上好用的 AI 工具。觉得有用就点个 Star ⭐ 支持一下，遇到问题直接提 Issue，我看到就修！
