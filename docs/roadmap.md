# Aurora 迭代路线图（10 轮增强计划）

> ✅ 全部完成：MVP 4 轮 + 迭代 10 轮，共 14 轮（含用户反馈修复轮），每轮构建 + 冒烟审计自审通过。

## 阶段一 · MVP（基础工作台）

- [x] R1 项目骨架：Electron 壳、三栏布局、毛玻璃、主题、交通灯、冒烟框架
- [x] R2 聊天核心：流式输出（主进程 SSE 转发）、Markdown/代码高亮/LaTeX、思考过程折叠、停止生成
- [x] R3 会话管理：SQLite（sql.js）持久化、增删改查、搜索、置顶、自动标题
- [x] R4 设置中心：模型配置（官方 + OpenAI 兼容端点）、参数调节、附件上传、打包

## 迭代 10 轮 ✅

1. [x] **命令行与快捷键**：命令面板 Ctrl+K、快捷键体系、全局唤起 Ctrl+Shift+A
2. [x] **对话增强**：消息编辑/重新生成/分支、复制、导出 Markdown/JSON
3. [x] **Token 与用量**：Token 统计、费用估算、首字/总耗时、用量总览
4. [x] **提示词系统**：系统提示词（全局+会话级）、模板库、白名单
5. [x] **工具链基础**：工具调用框架 + 步骤可视化卡片、文件读写（工作目录沙箱）
6. [x] **代码执行与命令**：Python/Shell 沙箱执行、系统命令确认弹窗、白名单
7. [x] **联网能力**：联网搜索（Bing 零配置）、网页抓取、URL 引用卡片
8. [x] **MCP 客户端**：stdio 握手/工具注册/调用、设置配置、Agent 接入
9. [x] **知识库 RAG**：本地文件夹索引、BM25 检索（中文 bigram）、引用溯源
10. [x] **打磨与加固**：错误重试、响应超时、数据备份、窗口记忆、最终打包
