# Aurora 迭代路线图（10 轮增强计划）

> 依据需求文档 + 开源 DeepSeek Harness 方案调研制定，每轮 = 功能 + 自审（构建/冒烟/截图）+ 修 bug。
> 参考开源方案：[deepseek-harness（官方/社区版）](https://github.com/HenryZ838978/deepseek-harness)、[tylerbuilds/deepseek-harness](https://github.com/tylerbuilds/deepseek-harness/releases)、社区测评（[36kr](https://eu.36kr.com/en/p/3938143940820104)、[橙皮书](https://github.com/alchaincyf/deepseek-harness-orange-book)）。

## 阶段一 · MVP（基础工作台）

- [ ] R1 项目骨架：Electron 壳、三栏布局、毛玻璃、主题、交通灯、冒烟框架
- [ ] R2 聊天核心：流式输出（主进程 SSE 转发）、Markdown/代码高亮/LaTeX、思考过程折叠、停止生成
- [ ] R3 会话管理：SQLite（sql.js）持久化、增删改查、搜索、置顶、自动标题
- [ ] R4 设置中心：模型配置（官方 + OpenAI 兼容端点）、参数调节、附件上传、打包

## 迭代 10 轮（每轮 1~3 个实用功能 + 修复上一轮自审发现的问题）

1. **命令行与快捷键**：全局快捷键唤起、⌘K 命令面板、会话快速切换、常用动作键位
2. **对话增强**：消息编辑/重新生成/分支、复制/朗读、导出 Markdown/JSON、上下文压缩提醒
3. **Token 与用量**：Token 统计、费用估算、响应耗时、模型参数抽屉
4. **提示词系统**：系统提示词编辑、提示词模板库、预设参数（温度等）快速套用
5. **工具链基础**（阶段二启动）：工具调用框架 + 步骤可视化卡片、文件读写（工作目录沙箱）
6. **代码执行与命令**：Python/Shell 沙箱执行、系统命令确认弹窗、白名单
7. **联网能力**：联网搜索、网页抓取、URL 内容引用卡片
8. **MCP 客户端**：参考开源 Harness 的 MCP Server 能力，接入 MCP 工具源
9. **知识库 RAG**（阶段三启动）：本地文件夹索引、本地嵌入、引用溯源面板
10. **打磨与加固**：错误重试、网络超时、数据备份、窗口状态记忆、性能优化、最终打包

## 候选备胎池（有空就塞进某轮）

- 会话归档/分组、拖拽排序
- 自定义强调色、紧凑模式、字体缩放
- 图片粘贴上传、多模态（兼容端点）
- 开机自启、托盘常驻、系统通知
- 数据导出/导入、自动备份
- i18n（中文/English）
- 代理设置、自定义请求头
