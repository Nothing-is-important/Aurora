# Aurora 使用教程

> 本教程面向普通用户，从零开始 5 分钟上手。

## 一、安装与启动

1. 下载安装包 `Aurora Setup 0.1.0.exe`，双击安装（可选安装目录，自动创建桌面快捷方式）
2. 启动后主界面为三栏布局：
   - **左栏**：会话列表（搜索、置顶、重命名）
   - **中栏**：对话区（消息流 + 输入框）
   - **右栏**：检查器（工具调用 / 引用 / 信息）

## 二、配置模型（必做）

1. 点击左栏左下角 **⚙ 设置**
2. 选择「DeepSeek Chat」：
   - **API Key**：在 [platform.deepseek.com](https://platform.deepseek.com) 创建后粘贴（本机 DPAPI 加密保存，不会上传）
   - 点击 **测试连接** → 显示"连接成功"即就绪
3. 兼容端点（Ollama / LM Studio / 中转站）：
   - 点「添加模型」→ 提供方选「OpenAI 兼容」→ 填 Base URL 与模型 ID（如 `http://localhost:11434/v1` + `qwen2.5`）
4. 参数调节：Temperature（创意性）、Max Tokens（最大长度）、Top P 可直接在表单里改，保存生效

## 三、开始对话

- 顶部药丸按钮切换模型（绿点 = 已就绪，橙点 = 未配 Key）
- 输入框按 `Enter` 发送，`Shift+Enter` 换行；流式输出可随时点红色方块**停止**
- 使用 `deepseek-reasoner` 时，回复上方出现「思考过程」折叠面板
- 首条消息自动生成会话标题；侧边栏双击标题可重命名，悬停可置顶/删除

### 消息操作
| 操作 | 方式 |
| --- | --- |
| 编辑并重新发送 | 悬停用户消息 →「编辑」→ 修改 → 保存（后续消息自动截断，形成分支） |
| 重新生成 | 悬停助手消息 →「重新生成」 |
| 复制 | 消息悬停「复制」；代码块右上角独立复制按钮 |
| 出错重试 | 错误卡片上的「重试」按钮 |
| 导出 | 右栏顶部 📄（Markdown）/ JSON 图标，或「信息」tab 内大按钮 |

## 四、快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + K` | 命令面板（搜索会话/切换模型/执行动作） |
| `Ctrl + N` | 新对话 |
| `Ctrl + ,` | 打开设置 |
| `Ctrl + 1~9` | 切换最近会话 |
| `Ctrl + Shift + A` | 全局唤起/最小化窗口 |
| `Esc` | 关闭弹窗/面板 |

## 五、附件与模板

- **附件**：输入框回形针选择文件
  - 图片：以多模态方式发送（仅 OpenAI 兼容端点；DeepSeek 官方暂不支持视觉，会忽略）
  - 文本/代码（<200KB）：内容内联进上下文
- **模板**：输入框书签按钮 → 6 个内置模板
  - 「填入输入框」类：翻译 / 代码审查 / 润色 / 周报
  - 「设为系统提示词」类：头脑风暴 / Python 专家（带 toast 确认）

## 六、系统提示词

- **全局**：设置 → 「系统提示词」textarea（所有会话生效）
- **会话级**：右栏「信息」tab → 「会话级系统提示词」（覆盖全局，优先级更高）

## 七、Agent 工具（进阶）

工具由模型自动发起，无需手动配置。全部限制在**工作目录沙箱**内：

```
%APPDATA%\Aurora\workspace\
```

| 工具 | 触发方式（自然语言） | 安全机制 |
| --- | --- | --- |
| 文件读写 | "把 xxx 写到文件里" | 仅限工作目录，防路径越界 |
| Python 执行 | "跑一下这段 Python" | 30 秒超时，需本机安装 Python |
| 系统命令 | "执行 xxx 命令" | **确认弹窗**（允许一次/始终允许/拒绝）+ 白名单 |
| 联网搜索 | "搜索一下 xxx" | Bing 零配置，结果带引用卡片 |
| 网页抓取 | "读一下这个网页" | 2MB 上限 |
| 知识库检索 | "查一下我的笔记里…" | 本地 BM25，文档不出本机 |

**命令白名单**：设置 → 「系统命令白名单」，每行一条，前缀匹配；`git ` 表示所有 git 命令，`echo*` 表示前缀通配。白名单内命令不再弹窗。

## 八、知识库

1. 设置 → 知识库 → **添加文件夹**（支持 md/txt/json/py/js/css 等 30+ 文本格式，单文件 <500KB）
2. 索引完成后，对话中说"检索知识库中关于 xxx 的内容"即可引用，来源卡片点击会用默认应用打开原文
3. 「重建索引」在文件变动后手动刷新；「移除」删除索引（不动原文件）

## 九、MCP 服务器（极客玩法）

1. 设置 → MCP 服务器 → 添加：名称 + 命令 + 参数
   - 示例：`npx -y @modelcontextprotocol/server-filesystem C:\MyDocs`（名称随意，命令 `npx`，参数 `-y @modelcontextprotocol/server-filesystem C:\MyDocs`）
2. 保存即自动连接，工具以 `mcp__服务器__工具` 形式对模型可见
3. 内置一个 `Mock MCP` 演示服务器可直接体验（需要 Node.js 环境）

## 十、数据与备份

| 内容 | 位置 |
| --- | --- |
| 会话/设置数据库 | `%APPDATA%\Aurora\aurora.db` |
| 知识库索引 | `%APPDATA%\Aurora\kb.sqlite` |
| 自动备份 | `%APPDATA%\Aurora\backups\`（每日一份，保留 7 份） |
| Agent 工作目录 | `%APPDATA%\Aurora\workspace\` |

## 十二、托盘与通知

- **托盘常驻**：Aurora 启动后驻留系统托盘（任务栏右下角）
  - 单击托盘图标：显示 / 隐藏窗口
  - 右键菜单：显示 Aurora / 最小化到托盘 / 退出
- **完成通知**：窗口隐藏或最小化时，回复完成后弹出系统通知，点击通知直接唤回窗口；窗口在前台时静默不打扰
- 快捷隐藏：`Ctrl+Shift+A` 再次按下可恢复

## 十三、常见问题

**Q：提示「尚未配置 API Key」？**
设置里填入 Key 并点测试连接；确认模型药丸是绿点。

**Q：测试连接超时？**
检查网络；如使用代理，在设置 → 网络代理中填写代理地址（如 `http://127.0.0.1:7890`）。

**Q：回复窗口为什么是全宽？**
这是设计决策：助手气泡固定全宽避免流式过程中宽度抖动。

**Q：系统命令弹窗烦？**
把常用命令加进白名单（弹窗选"始终允许"即可自动加入）。

**Q：数据怎么迁移？**
复制 `%APPDATA%\Aurora\` 下 `aurora.db`、`kb.sqlite` 到新机器同目录即可。
