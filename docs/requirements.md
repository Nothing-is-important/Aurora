# Aurora — DeepSeek Harness GUI 需求文档

> 版本：v1.0（2025 年确认稿）
> 形态：苹果设计风格的 DeepSeek Harness 桌面工作台
> 本文档内容全部经多轮对话确认，后续变更请同步更新本文档。

---

## 1. 项目概述

| 项目 | 内容 |
| --- | --- |
| 应用名称 | Aurora |
| 定位 | DeepSeek Harness 桌面 GUI，完整 Agent 工作台 |
| 设计语言 | 苹果（Apple）风格：毛玻璃材质、柔和圆角、弹簧动画、SF 字体族 |

## 2. 已确认需求

### 2.1 模型接入
- DeepSeek 官方 API（api.deepseek.com），支持 `deepseek-chat` / `deepseek-reasoner`
- OpenAI 兼容端点：可自定义 Base URL，接入 Ollama、LM Studio、中转站等
- 可保存多组模型配置，对话时切换模型
- 参数可调：temperature、top_p、max_tokens、上下文长度等

### 2.2 会话管理（本地持久化）
- 多会话列表，会话持久化到本地 SQLite
- 支持：新建、重命名、删除、搜索、置顶、标签/文件夹分组
- 会话内消息完整保留（含思考过程、工具调用记录）

### 2.3 输入与内容渲染
- 图片 / 文件附件（作为临时上下文）
- Markdown 完整渲染：标题、列表、表格、引用、链接
- 代码块语法高亮 + 一键复制
- LaTeX 公式渲染（行内 + 块级）
- 流式输出（打字机效果）
- 深色 / 浅色模式：跟随系统 + 手动切换

### 2.4 Agent 工具调用（真实执行）
- 模型发起的 tool call 由应用真实执行，结果回传模型
- 工具清单（全部确认需要）：
  1. **文件读写** — 限制在用户指定的工作目录内
  2. **代码执行** — 隔离沙箱中运行 Python / Shell 代码
  3. **联网搜索** — 内置网页搜索，获取实时信息
  4. **网页抓取** — 读取 URL 内容并总结分析
  5. **系统命令** — 风险最高，执行前弹出确认弹窗
- 工具调用过程在界面中可视化（步骤卡片、参数、结果、耗时）

### 2.5 知识库（本地 RAG）
- 指定本地文件夹 / 文档建立索引
- 对话中可检索引用（RAG），引用来源可溯源
- 向量化使用**本地嵌入模型**（如 ONNX 方案），文档内容不出本机

### 2.6 思考过程
- 使用 `deepseek-reasoner` 时展示思维链
- 以可折叠面板呈现，类似官方 App 的思考过程

## 3. 界面设计规格（苹果风格）

### 3.1 布局：三栏工作台
- **左栏**：毛玻璃侧边栏 — 会话列表、搜索、分组、设置入口
- **中栏**：对话区 — 消息流、输入框、附件、流式输出
- **右栏**：细节面板 — 工具调用步骤、知识库引用、会话信息，可折叠

### 3.2 视觉材质
- 完整毛玻璃：背景模糊（backdrop blur）、半透明分层
- 柔和圆角、精致阴影、细微弹簧动画（spring easing）
- 字体族：SF Pro 优先（系统上无 SF 时回退 Inter / Segoe UI）
- 深色模式像 macOS 原生应用

### 3.3 窗口
- 无边框窗口 + 红黄绿交通灯按钮（Windows 上自绘）
- 标题栏融入内容区（hiddenInset 风格）
- 窗口可拖拽、原生圆角

### 3.4 主题
- 跟随系统自动切换，同时提供手动切换（浅色 / 深色 / 跟随系统）

## 4. 技术栈

| 层 | 选型 |
| --- | --- |
| 桌面框架 | Electron（主进程 Node.js） |
| 前端 | React + TypeScript + Tailwind CSS |
| 数据存储 | SQLite（better-sqlite3） |
| 向量化 | 本地嵌入（ONNX 轻量模型，如 bge-small-zh / all-MiniLM） |
| 代码沙箱 | 待定（隔离子进程 / 容器化，阶段二细化） |
| 打包 | electron-builder（Windows NSIS 安装包） |

## 6. 风险与已定决策

| 风险点 | 决策 |
| --- | --- |
| 系统命令执行风险 | 执行前强制确认弹窗；后续可加命令白名单 |
| 本地嵌入模型体积/速度 | 选用轻量 ONNX 模型，首次建库提示耗时 |
| 文档内容隐私 | 全程本地向量化，不上传云端 |
| Windows 上实现苹果视觉 | 交通灯自绘、字体回退方案（Inter） |
| macOS 打包 | 当前在 Windows 开发，macOS 包后续在 Mac 上验证 |
